CORE ARCHITECTURE

Entity Component System (ECS)

Data-oriented design pattern ensuring maximum modularity, cache efficiency, and extensible entity logic.

🧩
Components (Pure Data)
Decoupled data containers without behavior:

• TransformComponent: 2D Coordinates, Velocity, Rotation, Scale.
• HealthComponent: Current HP, Max HP, Shields, Invulnerability Frames.
• PhysicsComponent: Bounding boxes, Mass, Friction, Spatial Hash Cells.
• InventoryComponent: Item slots, Equipment gear, Gold currency.
⚙️
Systems (Pure Logic)
Iterates over entities matching component bitmasks:

• Movement & Collision System: Continuous collision detection with tile bitmasks.
• Combat System: Damage mitigation, crit checks, knockback impulses.
• Status Effect System: Manages poison ticks, stuns, freezes, and speeds.
• Render System: Depth-sorted canvas drawing and particle emissive blending.
PROCEDURAL ALGORITHMS

Procedural Dungeon Generation

Multi-stage generation combining Binary Space Partitioning, cellular smoothing, and dynamic prop scattering.

🌲
BSP Room Carving
Recursively partitions dungeon boundaries into sub-trees, carving randomized non-overlapping rectangular chambers with minimum sizing rules.
🕸️
Delaunay & MST Corridors
Calculates Minimum Spanning Trees (Kruskal algorithm) between room centers, creating guaranteed traversable loops and secret hallways.
🏛️
Biome Theming & Props
Applies 4 distinct visual biomes (Crypt, Inferno, Abyssal, Glacial) with prop scattering (sarcophagi, lava vents, braziers, and spike traps).

MODDING & SECURITY

Data-Driven Modding & Save Security

Enterprise-grade architecture for community content extensibility and tamper-proof save integrity.

🔌
Sandboxed JSON Modding API
• Schema Validator: Validates JSON manifests for community-authored weapons, monsters, and quests.
• Blueprint Hooks: Allows players to inject custom dungeon room matrices and custom spawn triggers.
• Hot Reloading: Dynamically registers modded entities into the master catalog without rebuilding the engine.
🛡️
Encrypted Saves & Backup Rotation
• HMAC-SHA256 Signatures: Detects manual file tampering and prevents memory injection cheating.
• Multi-Slot Backup Manager: Automatically rotates up to 5 timestamped save snapshots.
• Schema Migration Pipeline: Backwards-compatible save upgrade engine across game versions.
